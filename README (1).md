## 🎯 About Me

- 🔧 **8 years in IT** — most of it inside the SAP integration world
- 🎯 Now building with **C# / .NET**, applying that integration mindset to modern software
- 🤖 Exploring **AI** as a second learning track
- 🧩 Not starting from zero — I know how systems break, and what it takes to keep them talking to each other

<details>
<summary>📖 The full story</summary>
<br>

I spent the last few years building integrations inside the SAP ecosystem — ABAP, IDocs, RFCs, PI/PO, and CPI — connecting systems that weren't built to talk to each other. That work taught me a lot about how enterprise systems actually communicate, and it's what pulled me toward development itself.

I'm now transitioning into C# / .NET, focused on applying that integration mindset to modern software — APIs, services, and systems that need to exchange data reliably. Alongside that, I'm exploring AI, mostly around how LLMs and automation can plug into the kind of integration work I already know well.

Still early in this path, but not starting from zero.

</details>
